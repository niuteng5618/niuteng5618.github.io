### <font style="color:rgb(51, 51, 51);">✅</font><font style="color:rgb(51, 51, 51);"> </font>**<font style="color:rgb(51, 51, 51);">基本请求统计</font>**
1. **<font style="color:rgb(51, 51, 51);">Successful requests</font>****<font style="color:rgb(51, 51, 51);">含义</font>**<font style="color:rgb(51, 51, 51);">：压测过程中成功完成的请求数（未超时、未报错）。</font>**<font style="color:rgb(51, 51, 51);">作用</font>**<font style="color:rgb(51, 51, 51);">：反映服务稳定性，成功率过低说明接口或硬件负载能力不足。</font>
2. **<font style="color:rgb(51, 51, 51);">Maximum request concurrency</font>****<font style="color:rgb(51, 51, 51);">含义</font>**<font style="color:rgb(51, 51, 51);">：本次测试设置的最大并发请求数，即同时发出的请求数量上限。</font>**<font style="color:rgb(51, 51, 51);">作用</font>**<font style="color:rgb(51, 51, 51);">：模拟真实场景的并发压力，数值越高，服务端压力越大。</font>
3. **<font style="color:rgb(51, 51, 51);">Benchmark duration (s)</font>****<font style="color:rgb(51, 51, 51);">含义</font>**<font style="color:rgb(51, 51, 51);">：整个测试运行的时间（单位：秒）。</font>**<font style="color:rgb(51, 51, 51);">作用</font>**<font style="color:rgb(51, 51, 51);">：用于计算吞吐量、性能曲线。</font>

---

### <font style="color:rgb(51, 51, 51);">✅</font><font style="color:rgb(51, 51, 51);"> </font>**<font style="color:rgb(51, 51, 51);">Token统计相关</font>**
1. **<font style="color:rgb(51, 51, 51);">Total input tokens</font>****<font style="color:rgb(51, 51, 51);">含义</font>**<font style="color:rgb(51, 51, 51);">：所有请求的输入文本（Prompt）Token 总数。</font>**<font style="color:rgb(51, 51, 51);">作用</font>**<font style="color:rgb(51, 51, 51);">：衡量输入负载大小，影响内存和推理速度。</font>
2. **<font style="color:rgb(51, 51, 51);">Total generated tokens</font>****<font style="color:rgb(51, 51, 51);">含义</font>**<font style="color:rgb(51, 51, 51);">：所有请求生成的输出 Token 总数。</font>**<font style="color:rgb(51, 51, 51);">作用</font>**<font style="color:rgb(51, 51, 51);">：衡量模型输出负载，是 GPU 解码阶段性能的关键指标。</font>

---

### <font style="color:rgb(51, 51, 51);">✅</font><font style="color:rgb(51, 51, 51);"> </font>**<font style="color:rgb(51, 51, 51);">吞吐量指标</font>**
1. **<font style="color:rgb(51, 51, 51);">Request throughput (req/s)</font>****<font style="color:rgb(51, 51, 51);">含义</font>**<font style="color:rgb(51, 51, 51);">：每秒成功处理的请求数。</font>**<font style="color:rgb(51, 51, 51);">计算</font>**<font style="color:rgb(51, 51, 51);">：</font>`<font style="color:rgb(51, 51, 51);background-color:rgb(243, 244, 244);">Successful requests / Benchmark duration</font>`**<font style="color:rgb(51, 51, 51);">作用</font>**<font style="color:rgb(51, 51, 51);">：评估整体请求处理能力。</font>
2. **<font style="color:rgb(51, 51, 51);">Output token throughput (tok/s)</font>****<font style="color:rgb(51, 51, 51);">含义</font>**<font style="color:rgb(51, 51, 51);">：每秒生成的 </font>**<font style="color:rgb(51, 51, 51);">输出 Token 数</font>**<font style="color:rgb(51, 51, 51);">（即模型解码速度）。</font>**<font style="color:rgb(51, 51, 51);">计算</font>**<font style="color:rgb(51, 51, 51);">：</font>`<font style="color:rgb(51, 51, 51);background-color:rgb(243, 244, 244);">Total generated tokens / Benchmark duration</font>`**<font style="color:rgb(51, 51, 51);">作用</font>**<font style="color:rgb(51, 51, 51);">：反映 </font>**<font style="color:rgb(51, 51, 51);">输出速度</font>**<font style="color:rgb(51, 51, 51);">，是最关键指标之一。</font>
3. **<font style="color:rgb(51, 51, 51);">Total Token throughput (tok/s)</font>****<font style="color:rgb(51, 51, 51);">含义</font>**<font style="color:rgb(51, 51, 51);">：每秒处理的 Token 总数（包括输入和输出）。</font>**<font style="color:rgb(51, 51, 51);">计算</font>**<font style="color:rgb(51, 51, 51);">：</font>`<font style="color:rgb(51, 51, 51);background-color:rgb(243, 244, 244);">(Total input tokens + Total generated tokens) / Benchmark duration</font>`**<font style="color:rgb(51, 51, 51);">作用</font>**<font style="color:rgb(51, 51, 51);">：衡量整体 Token 处理效率。</font>

---

### <font style="color:rgb(51, 51, 51);">✅</font><font style="color:rgb(51, 51, 51);"> </font>**<font style="color:rgb(51, 51, 51);">延迟指标</font>**
#### **<font style="color:rgb(51, 51, 51);">TTFT (Time To First Token)</font>**
1. **<font style="color:rgb(51, 51, 51);">Mean TTFT (ms)</font>****<font style="color:rgb(51, 51, 51);">含义</font>**<font style="color:rgb(51, 51, 51);">：平均首 Token 延迟，即请求发出到生成第一个 Token 的时间。</font>**<font style="color:rgb(51, 51, 51);">作用</font>**<font style="color:rgb(51, 51, 51);">：评估 </font>**<font style="color:rgb(51, 51, 51);">首响应速度</font>**<font style="color:rgb(51, 51, 51);">，影响用户体验。</font>
2. **<font style="color:rgb(51, 51, 51);">Median TTFT (ms)</font>****<font style="color:rgb(51, 51, 51);">含义</font>**<font style="color:rgb(51, 51, 51);">：首 Token 延迟的中位数，比平均值更抗异常值影响。</font>**<font style="color:rgb(51, 51, 51);">作用</font>**<font style="color:rgb(51, 51, 51);">：更准确反映大多数请求的真实延迟。</font>
3. **<font style="color:rgb(51, 51, 51);">P99 TTFT (ms)</font>****<font style="color:rgb(51, 51, 51);">含义</font>**<font style="color:rgb(51, 51, 51);">：99% 请求的首 Token 延迟不超过该值（极端场景）。</font>**<font style="color:rgb(51, 51, 51);">作用</font>**<font style="color:rgb(51, 51, 51);">：衡量 </font>**<font style="color:rgb(51, 51, 51);">最差性能（长尾问题）</font>**<font style="color:rgb(51, 51, 51);">。</font>

---

#### **<font style="color:rgb(51, 51, 51);">TPOT (Time per Output Token)</font>**
1. **<font style="color:rgb(51, 51, 51);">Mean TPOT (ms)</font>****<font style="color:rgb(51, 51, 51);">含义</font>**<font style="color:rgb(51, 51, 51);">：平均每个输出 Token（不包括首 Token）生成所需时间。</font>**<font style="color:rgb(51, 51, 51);">作用</font>**<font style="color:rgb(51, 51, 51);">：衡量模型的 </font>**<font style="color:rgb(51, 51, 51);">解码速度</font>**<font style="color:rgb(51, 51, 51);">。</font>
2. **<font style="color:rgb(51, 51, 51);">Median TPOT (ms)</font>****<font style="color:rgb(51, 51, 51);">含义</font>**<font style="color:rgb(51, 51, 51);">：每个 Token 输出延迟的中位数。</font>**<font style="color:rgb(51, 51, 51);">作用</font>**<font style="color:rgb(51, 51, 51);">：反映典型解码性能。</font>
3. **<font style="color:rgb(51, 51, 51);">P99 TPOT (ms)</font>****<font style="color:rgb(51, 51, 51);">含义</font>**<font style="color:rgb(51, 51, 51);">：99% 请求的每个输出 Token 延迟不超过该值。</font>**<font style="color:rgb(51, 51, 51);">作用</font>**<font style="color:rgb(51, 51, 51);">：检查极端情况下的性能。</font>

---

#### **<font style="color:rgb(51, 51, 51);">ITL (Inter-token Latency)</font>**
1. **<font style="color:rgb(51, 51, 51);">Mean ITL (ms)</font>****<font style="color:rgb(51, 51, 51);">含义</font>**<font style="color:rgb(51, 51, 51);">：连续两个 Token 之间的平均延迟（比 TPOT 更直接表示流式生成速度）。</font>**<font style="color:rgb(51, 51, 51);">作用</font>**<font style="color:rgb(51, 51, 51);">：衡量 </font>**<font style="color:rgb(51, 51, 51);">模型生成平滑度</font>**<font style="color:rgb(51, 51, 51);">，影响流式输出体验。</font>
2. **<font style="color:rgb(51, 51, 51);">Median ITL (ms)</font>****<font style="color:rgb(51, 51, 51);">含义</font>**<font style="color:rgb(51, 51, 51);">：Token 间延迟的中位数。</font>**<font style="color:rgb(51, 51, 51);">作用</font>**<font style="color:rgb(51, 51, 51);">：真实体验的参考指标。</font>
3. **<font style="color:rgb(51, 51, 51);">P99 ITL (ms)</font>****<font style="color:rgb(51, 51, 51);">含义</font>**<font style="color:rgb(51, 51, 51);">：99% 请求的 Token 间延迟不超过该值。</font>**<font style="color:rgb(51, 51, 51);">作用</font>**<font style="color:rgb(51, 51, 51);">：反映长尾 Token 生成速度问题。</font>
